# NuKit Vision

> Where we're going and why it matters

**This document defines WHERE WE'RE GOING.** For who we are, see [CONSTITUTION.md](./CONSTITUTION.md).

## What is NuKit?

NuKit is a **production-ready starter template** for building modern frontend AI applications. It combines the best-in-class tools for rapid development:

- **Nuxt 4** - Vue.js meta-framework with file-based routing, auto-imports, and SSR
- **NuxtUI** - Beautiful, accessible component library built on Tailwind CSS
- **Convex** - Realtime backend with reactive queries and serverless functions
- **Better Auth** - Flexible authentication with multiple providers

## Why NuKit?

### The Problem
Building AI-powered frontend apps requires too much boilerplate:
- Setting up auth from scratch
- Configuring realtime data sync
- Building a design system
- Wiring everything together

### Our Solution
Start with everything wired up. Focus on your unique features, not infrastructure.

## Target Audience

- **Indie hackers** building AI-powered tools
- **Startups** needing rapid prototyping
- **Developers** who want best practices out of the box

## Core Principles

### 1. Convention Over Configuration
Sensible defaults that just work. Escape hatches when you need them.

### 2. Realtime First
Convex's reactive queries make real-time the default, not an afterthought.

### 3. AI-Native Development
Built for human-AI collaboration with comprehensive documentation and clear patterns.

### 4. Production Ready
Not a toy—security, performance, and accessibility built in from day one.

## Success Looks Like

- Clone → configure → deploy in under 30 minutes
- Clear patterns for common AI app features (chat, streaming, embeddings)
- Beautiful UI without design expertise
- Scales from prototype to production without rewrites
